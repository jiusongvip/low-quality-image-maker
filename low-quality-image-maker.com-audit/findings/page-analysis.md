 - 8/10 images have explicit `width="400" height="400"` for CLS prevention

 ### Issues

 **s|Medium| 2 upload-zone images missing dimensions**
 The upload preview and result images (dynamic, set via JS) lack width/height. These are in the drop-zone and result-zone containers with `aspect-square`, which mitigates CLS but explicit dimensions would be better.

 **s|Medium| No responsive images / srcset**
 All demo images are 400×400. Mobile users could benefit from 200×200 variants via srcset. Cloudflare Polish may handle this on deploy.

 **s|Low| No WebP/AVIF versions**
 Modern format support would reduce demo image payload further. Can be handled by Cloudflare Polish or manual WebP generation.
